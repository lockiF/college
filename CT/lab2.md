### 2. Огляд трьох найбільших світових провайдерів

- **AWS (Amazon Web Services)** — найстаріша й найбільша хмарна платформа. Має понад 200 сервісів: віртуальні сервери (EC2), сховище (S3), бази даних (RDS, DynamoDB), аналітику, міграцію даних, AI/ML.
- **Microsoft Azure** — хмара Microsoft. Найкраще інтегрована з продуктами компанії (Windows Server, .NET, Microsoft 365), добре підтримує гібридні рішення, коли частина інфраструктури лишається на власних серверах.
- **GCP (Google Cloud Platform)** — хмара Google. Сильна в аналізі даних, машинному навчанні та Kubernetes, бо використовує ті ж технології, що й сервіси самого Google.

|---|---|---|---|

### 4. Перспективні напрямки та нові рішення

Головний напрямок розвитку всіх трьох провайдерів однаковий: **AI-агенти** (програми на основі ШІ, які самі виконують завдання) та **власні чипи** для ШІ, щоб залежати від NVIDIA менше й знизити вартість.

**AWS** (re:Invent, грудень 2025):
- Trainium3 UltraServers — нове покоління власних AI-чипів на 3 нм для навчання й запуску моделей.
- Graviton5 — найпотужніший процесор AWS.
- Amazon Bedrock AgentCore — керована платформа для створення й запуску AI-агентів, з новими функціями політик доступу та оцінки якості.
- «Frontier agents» (наприклад, Kiro) — агенти, які працюють як віртуальний розробник і можуть виконувати завдання кілька днів.
- AWS AI Factories — AI-системи AWS, які розгортаються у власних дата-центрах клієнта (для держструктур і регульованих галузей).
- У Bedrock додали 18 моделей з відкритими вагами.

**Microsoft Azure** (Ignite, листопад 2025):
- Microsoft Foundry — єдина платформа для створення AI-застосунків і агентів (наступник Azure AI Foundry), з підтримкою моделей Anthropic.
- Azure Cobalt 200 — новий ARM-процесор власної розробки, приблизно на 50% швидший за попередній.
- Azure Boost — нове покоління прискорення мережі та сховища (до 400 Гбіт/с).
- Fairwater — найбільші AI-дата-центри Microsoft, Azure першою запустила GPU NVIDIA GB300 у великому масштабі.
- Azure Copilot з вбудованими агентами для керування хмарою та Azure HorizonDB (PostgreSQL з ШІ).

**Google Cloud** (Next, квітень 2026):
- Gemini Enterprise Agent Platform — Vertex AI перейменували й розширили до повноцінної платформи для створення, запуску й контролю AI-агентів.
- TPU 8t і TPU 8i — восьме покоління чипів Google: перший для навчання (до 9 600 чипів в одному кластері), другий для інференсу (приблизно на 80% вигідніший за ціною/продуктивністю, ніж попередній Ironwood).
- Ironwood TPU та процесори Axion стали загальнодоступними.
- Agentic Data Cloud — хмара даних, яка автоматично розмічає й зв'язує корпоративні дані, щоб агенти розуміли контекст.
- Захист на основі Wiz (Google придбала цю компанію для безпеки хмар).

### 5. Топ-5 українських постачальників хмарних послуг

За оглядами 2022-2026 років (дослідження Molfar, рейтинг KyivTime 2026) на українському ринку найчастіше називають:

1. **GigaCloud** — найбільший український хмарний провайдер, основний постачальник приватних хмар.
2. **De Novo** — провайдер IaaS на VMware, з акцентом на Kubernetes і AI/GPU.
3. **«Парковий»** — комерційний дата-центр із власною хмарною платформою.
4. **Tetcloud** — лідер за технічною підтримкою й технічною частиною в дослідженні Molfar 2022.
5. **UCloud** — базові IaaS-рішення, орієнтований на малий і середній бізнес.

### 7. Вибір платформи для власного хмарного сервера

**Світова платформа: AWS.**
Вона має найширший набір сервісів, тому під будь-яке завдання (сайт, база даних, бот, навчання моделі) знайдеться готове рішення. Є безкоштовний рівень для початку, величезна кількість документації та прикладів і можливість спочатку взяти маленький сервер, а потім масштабувати його. Мінус — складна панель керування й тарифи, за якими легко переплатити.

**Українська платформа: GigaCloud.**
Це найбільший український провайдер із дата-центрами в Україні, тому дані залишаються в країні, а затримка мінімальна. Має сертифікати безпеки, підтримку українською й може працювати з вимогами українських регуляторів. Якщо проєкту потрібна інфраструктура з дотриманням українського законодавства, такий варіант зручніший за закордонну хмару.

## Висновки

Під час лабораторної роботи я ознайомився з трьома найбільшими світовими хмарними провайдерами (AWS, Azure, GCP), порівняв їхні можливості за 7 критеріями та розглянув, які нові рішення вони випустили останнім часом. Головні напрямки розвитку: AI-агенти та власні чипи для штучного інтелекту.

Також я дослідив український ринок хмарних послуг і порівняв трьох найбільш конкурентних провайдерів: GigaCloud, De Novo та «Парковий». Вони пропонують сертифіковану інфраструктуру в Україні, що важливо для бізнесу й держсектору.

Світові провайдери вигідніші масштабом і кількістю сервісів, українські — контролем над даними, відповідністю місцевому законодавству та підтримкою. Вибір залежить від завдання: для гнучкої розробки й експериментів зручніше AWS, для проєктів із вимогами до зберігання даних в Україні — український провайдер.
